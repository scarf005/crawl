# TextDB Gettext Catalogs

This directory is reserved for gettext catalogs generated from low-hanging
`TextDB` content.

- `crawl-data.pot` is generated by `make pot-data`.
- `*.po` files can be bootstrapped from legacy translation directories with
  `python3 util/textdb-legacy-to-po.py <lang>`.
- compiled catalogs are written to `source/locale/<lang>/LC_MESSAGES/` by
  `make compile-mo`.

The initial gettext migration only covers the `TextDB` databases that already
behave like externalized descriptive content. Legacy translation directories
remain authoritative for everything else.
